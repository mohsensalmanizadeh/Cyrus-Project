# Cyrus – The Great

A responsive website dedicated to **Cyrus the Great**, exploring his legacy, the Achaemenid Empire, and his historical contributions to Persian civilization.

This project was developed collaboratively to practice and improve our front-end development skills, focusing on building a visually appealing and responsive user interface using HTML, CSS, and JavaScript.

### Features
- Responsive layout for different screen sizes
- Custom navigation menu
- Modern UI with a historical theme
- CSS animations and transitions
- Custom styling and typography
- Interactive elements

### Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome
